# Q1 Voice Agent Call Recordings

This directory stores audio recordings (`.wav`, `.mp3`, `.webm`) of live Vapi or Web Simulator test calls for Question 1: Knowledge-Grounded Business Loan Qualification Agent.

## Storage Structure
- `q1_test_001_cooperative.wav`: Audio recording of Test 1 (Cooperative Qualification).
- `q1_test_002_objection.wav`: Audio recording of Test 2 (Interest Rate Objection).
- `q1_test_003_conflicting.wav`: Audio recording of Test 3 (Conflicting Revenue Details).
- `q1_test_004_out_of_scope.wav`: Audio recording of Test 4 (Out-of-Scope Fallback).
- `q1_test_005_escalation.wav`: Audio recording of Test 5 (Human Agent Escalation Request).

> ℹ️ **Note**: Recordings are saved locally and ignored by git (`.gitignore`) to avoid committing large binary files or audio credentials.
