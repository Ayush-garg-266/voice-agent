# Q3 — Native-Language Voice Bots

This module implements localized voice bot engines for SE Asian financial conversations.

## Module Structure
- `philippines/`: English + Tagalog + Taglish bancassurance / business loan scripts & prompt overrides.
- `indonesia/`: Bahasa Indonesia formal/colloquial & regional accent configuration.
- `localization/`: Cultural tone, honorific rules (po/opo, Bapak/Ibu), and date/currency formatters.
- `language/`: Language detection and code-switching parsers.
- `tests/`: Code-switching & localization unit tests.
- `evaluation/`: Multilingual call transcript scoring harness.
